2.1. Captura ADB correta e robusta

O módulo adb_capture.py deve usar adb exec-out screencap -p (ou adb shell screencap -p) e decodificar bytes diretamente para OpenCV — não depender de screenshots via ImageGrab quando o objetivo é BlueStacks/ADB.

Deve haver verificação de adb disponível e timeout em comandos.

Ler a resolução do dispositivo via adb shell wm size e armazenar (width, height) para escalonamento de coordenadas.

Exemplo mínimo robusto (substituir no adb_capture.py):

import subprocess, numpy as np, cv2

def adb_screencap(adb_path="adb", device_id=None, timeout=5):
    cmd = [adb_path] + (["-s", device_id] if device_id else []) + ["exec-out", "screencap", "-p"]
    p = subprocess.run(cmd, capture_output=True, timeout=timeout)
    data = p.stdout
    img = cv2.imdecode(np.frombuffer(data, dtype=np.uint8), cv2.IMREAD_COLOR)
    return img  # BGR OpenCV

Captura ADB (robusta):

# adb_capture.py - função exemplar
import subprocess, numpy as np, cv2

class AdbCapture:
    def __init__(self, adb_path="adb", device_id=None, timeout=5):
        self.adb_path = adb_path
        self.device_id = device_id
        self.timeout = timeout

    def screencap(self):
        cmd = [self.adb_path] + (["-s", self.device_id] if self.device_id else []) + ["exec-out", "screencap", "-p"]
        try:
            p = subprocess.run(cmd, capture_output=True, timeout=self.timeout, check=True)
            data = p.stdout
            img = cv2.imdecode(np.frombuffer(data, dtype=np.uint8), cv2.IMREAD_COLOR)
            return img  # BGR
        except subprocess.TimeoutExpired:
            raise RuntimeError("ADB screencap timeout")
        except subprocess.CalledProcessError as e:
            raise RuntimeError(f"ADB error: {e}")

Action wrapper com dry-run e retries:

class AdbActions:
    def __init__(self, adb_path="adb", dry_run=False):
        self.adb_path = adb_path
        self.dry_run = dry_run

    def tap(self, x, y, retries=2):
        if self.dry_run:
            print(f"[DRYRUN] tap {x},{y}")
            return True
        cmd = [self.adb_path, "shell", "input", "tap", str(x), str(y)]
        for i in range(retries):
            try:
                subprocess.run(cmd, check=True, timeout=2)
                return True
            except Exception as e:
                time.sleep(0.1)
        return False
